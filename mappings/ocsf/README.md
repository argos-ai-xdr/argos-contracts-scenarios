# Mapping OCSF

`security-event` (`../../schemas/security-event/v1.schema.json`) está alineado con OCSF (Open Cybersecurity Schema Framework) — ADR-001. Este directorio documenta la correspondencia campo a campo entre el envelope+`security-event` v1 y las clases OCSF relevantes (p. ej. `Base Event`, `Network Activity`, `Process Activity`).

Pendiente (ARG-004/ARG-015): tabla de mapping real por clase OCSF una vez se fije qué eventos produce cada fuente (Wazuh, Falco, Hubble, Kubernetes Audit).
